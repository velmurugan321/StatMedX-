# StatMedX — Validation & Cross-Validation Report (Module 15)

Run the full battery:

```bash
cd backend && .venv/bin/pytest app/tests -v      # 56 checks
```

Three layers:

1. **Numerical references** (`test_validation.py`) — hand-computed values
   (Kaplan-Meier on a 6-point dataset, diagnostic measures, perfect/random AUC)
   and scipy/statsmodels cross-checks, reproducibility & tolerance tests.
2. **R cross-validation** (`test_r_crossvalidation.py`) — the engine is run on
   the *actual R datasets* (sleep, mtcars, InsectSprays, airquality) and compared
   against values computed by **real R 4.6.0** (WebR/WASM). References:
   `fixtures/r_references.json`, regenerated by `crossval/make_r_references.mjs`.
3. **Stata anchors** (`test_stata_anchors.py`) — official Stata-documented
   outputs (stata.com `ttesti` worked example, Stata manual `tabi` examples).
   `crossval/stata_verification.do` reproduces everything for Stata licence
   holders.

## Known, documented divergences (not bugs)

1. **Mann-Whitney with ties.** R 4.6 computes the tie-aware *exact midrank
   permutation* p. The engine does the same when C(N, n₁) ≤ 500 000
   (sleep: 0.065817 = R to 6 dp; SciPy's integer-U exact table would give
   0.0693 — this is precisely the discrepancy the engine upgrade removes).
   For larger tie-heavy samples the engine uses the normal approximation
   (mtcars hp: 0.0457 vs R 0.0435 — documented ±0.01 tolerance).
2. **Fisher exact odds ratio (2×2).** R/Stata report the conditional MLE;
   SciPy reports the sample OR. p-values are identical. The engine now computes
   **r×c Fisher exact p by full enumeration** with the same probability
   ordering as R/Stata (`tabi` manual example → 0.7073 vs Stata 0.707 ✅).
3. **stata.com Welch df typo.** The tutorial prints df = 35.3564 but its own CI
   is consistent with the Satterthwaite df = 33.914 (real R: 33.9142, CI
   [2.3113, 7.6887]). The engine follows the Satterthwaite/R convention.

## Engine improvements that came out of this battery

- `mannwhitney`: exact tie-aware permutation p (R parity) with method note.
- `crosstab, fisher`: r×c Fisher exact via full enumeration (was 2×2-only).
- `ttest_two`: pooled-mode SE/CI now use the pooled-variance SE (Stata/R parity).
- `correlation`: fixed broken scatter-figure import.
